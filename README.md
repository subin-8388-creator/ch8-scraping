# 대한민국 천만 관객 영화 분석기

위키백과의 '대한민국의 영화 흥행 기록' 문서에서 천만 관객 돌파 한국 영화 데이터를 웹 스크래핑으로 수집하고, 데이터를 정제하여 시각화 대시보드로 보여주는 Streamlit 웹 애플리케이션입니다.

## 주요 기능

1. **웹 데이터 수집**: 입력된 위키백과 URL에서 HTML 문서를 가져옵니다. (User-Agent 헤더 설정 및 시간 초과/연결 오류 예외 처리 포함)
2. **표 파싱 및 정제**: 
   - 각주 태그(`sup`) 제거 후 조건에 맞는 표(`wikitable`) 추출
   - 영화 제목의 겹낫표(`《》`) 제거 및 관객수 정수형 변환
   - 개봉일 데이터에서 개봉연도와 개봉월 분리 추출
3. **데이터 시각화 대시보드**:
   - 핵심 흥행 지표 (총 천만 영화 수, 역대 1위 영화, 역대 1위 관객수)
   - 정제된 전체 데이터 표 조회
   - 관객수 상위 10편 가로 막대 차트
   - 개봉연도별 천만 영화 편수 막대 차트
